# Aradhana · आराधना

**The inner temple.** A small suite of bhakti practices, together as one product.

Live: [darshakbhatt-aiproductlabs.github.io/aradhana](https://darshakbhatt-aiproductlabs.github.io/aradhana/)

## Four doors

| Practice | What it is |
| --- | --- |
| **Japa** | A mala for counting the Name — tap, cinematic auto-japa, flower shower, child’s palette. |
| **Path** | Lyric Walker. Follow a hymn word by word, as a finger on the page. |
| **Puja** | Manas puja to Shiva — nine offerings in the mind, with nine forms of the Lord. |
| **Murti** | Place a deity (or your own image). Touch it. Aura, aarti, lotus, tandava — the murti wakes. |

No account. Preferences stay on the device.

## Use it

1. Open the live site (or this preview).
2. From the temple courtyard, pick a door — or use the tabs along the bottom.
3. **Murti:** choose a form, or upload a photograph. Tap the figure. Open *Customize* to change aura, intensity, breath, and the temple bell.
4. **Japa / Path / Puja** keep the original flows: setup, recitation, cinematic.
